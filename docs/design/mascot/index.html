The crab, in vector and alive

Hermit's mascot is the reference drawing. The app now draws it from the rig's own traced pieces as vectors, and moves it only by moving, turning and scaling those pieces. This page is the proof that nothing was redrawn.

Every picture here is produced by node apps/mobile/preview/mascot/proof.mjs from the real component (apps/mobile/src/components/Mascot.tsx), in Chrome with GPU rasterization, the way docs/brand/mascot/png was made. The renders and clips sit in out/, which is not committed; run the script to fill or refresh this page.
