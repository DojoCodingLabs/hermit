The real screens from apps/mobile/src, rendered by the preview harness (apps/mobile/preview, react-native-web in headless Chromium at 412 by 915, 2x) with sample data, in the brand faces the app now bundles. Accessibility, measured

Contrast is measured on each picture: in every run of text the most common color is the background actually behind it and the strongest color away from it is the ink actually drawn (opacity and overlays included); 4.5:1 for text, 3:1 for large text and icons. Touch targets from the rendered size of every button, link, switch and radio. With a sheet open only the sheet is audited.

244 pictures audited: 2477 runs of text and 1056 icons measured on the pixels; 0 text runs under WCAG 2.2 AA, 0 icons under 3:1, 0 touch targets under 48 dp.

Writing slips found on the same pictures (a mono value ending on one or two characters, a line repeating the one before it, a row description past two lines, a fallback label): 0.
