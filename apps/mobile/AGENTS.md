This is Hermit's Expo and React Native app. The rules in the root [AGENTS.md](../../AGENTS.md) come first: read them before you change anything here.

## Expo changes often: check the docs for this version

Expo ships breaking changes with each SDK. APIs you remember may be renamed, moved or removed. Before you write code that touches an Expo or React Native API:

1. Read the major version of the `expo` package in `package.json`.
2. Read the matching versioned docs: `https://docs.expo.dev/versions/v<major>.0.0/`
3. For anything else, start from https://docs.expo.dev/llms.txt, an index of the Expo docs, and follow its links to the page you need.

## Commands

Run these from the repository root, with pnpm (Corepack picks the version `package.json` pins):

```bash
pnpm --filter @hermit/mobile exec expo install <package>   # adds a package at the version this SDK supports
pnpm --filter @hermit/mobile start                         # the dev server (Metro), for a development build
pnpm typecheck                                             # every workspace, the app included
pnpm test                                                  # every workspace's tests
```

The app isn't linted yet: `eslint.config.js` skips `apps/mobile`. Match the code around your change.

## Navigation

- Expo Router: routes live in `src/app/`, every file there is a screen, and `_layout.tsx` files define navigators. Keep components, hooks and helpers outside `src/app/`.
- Import `Link`, `router` and `useLocalSearchParams` from `expo-router`.

## Building

Hermit doesn't use EAS. Build the Android app with Gradle, as [CONTRIBUTING.md](../../CONTRIBUTING.md#build-the-android-app) says; preview APKs come from `.github/workflows/release-apk.yml`. Never add `expo-updates` or EAS Update: the app never takes code from a server.

## Rules

- `android/` and `ios/` are generated by `expo prebuild` (Continuous Native Generation). Don't edit them by hand: configure native behavior in `app.json` and the config plugins in `plugins/`.
- Expo Go can't run Hermit, because Hermit needs its own native modules. Use a development build, as CONTRIBUTING.md says.
- A new dependency needs its reason in the pull request, and none may call the network on its own or add telemetry (root AGENTS.md).
